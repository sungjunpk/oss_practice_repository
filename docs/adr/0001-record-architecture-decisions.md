# ADR-0001: 아키텍처 결정을 ADR 로 기록한다

- 상태: Accepted
- 날짜: 2026-11-11

## 맥락
모델 구조·데이터 소스·저장소 같은 결정이 채팅과 기억에만 남으면 학기 후반에 "왜 이렇게 했는지"를 복원할 수 없다.

## 결정
`docs/adr/` 에 Markdown ADR 을 번호순으로 저장한다. 논의는 Discussions 의 RFC 카테고리에서, 확정은 ADR PR 로 한다.

## 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| Wiki 에만 기록 | 편집이 쉬움 | PR 리뷰·이력 추적이 약함 |
| 기록 안 함 | 비용 0 | 근거 소실 |

## 결과
결정 이력이 코드와 같은 PR 흐름으로 리뷰된다. 대신 작성 부담이 조금 생긴다.
